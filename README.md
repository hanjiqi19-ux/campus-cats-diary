# 校猫日记

校园猫猫记录与展示体验版，包含猫猫大学搜索、学校和猫咪主页、热门动态、校猫日记、活动及手机适配。

## GitHub Pages 部署

本目录是可以直接发布的静态网站，不需要安装依赖或构建。

1. 将本目录所有内容上传到公开仓库的 main 分支根目录，保留 assets 文件夹和 .nojekyll。
2. 在仓库 Settings → Pages 中，选择 Deploy from a branch。
3. 分支选择 main，目录选择 /(root)，点击 Save。
4. 等待 GitHub 的 Pages 部署完成，以 Pages 设置页显示的网址为准。

首页使用相对资源路径和 # 路由，可以在 GitHub Pages 的仓库子路径下使用。

## 体验版说明

- 当前是静态演示站；发布、关注、收藏、日记和草稿保存在当前浏览器中，不会在不同用户或设备之间共享。
- 更换域名不会自动迁移原地址浏览器中保存的数据。
- 暂不包含真实账号登录、社团身份认证或服务端数据库。
- 微信内访问需部署后实际测试。

页面和资源来自现有校猫日记网站，保留 PC 和手机端界面。
